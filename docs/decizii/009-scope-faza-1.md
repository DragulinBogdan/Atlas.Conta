## Regula durabilă

**Scope faza 1: contabilitate + gestiune**, plățile/încasările ca documente.
Salarizare, imobilizări, execuție = module separate, intră prin note
contabile (NTC, 46b).

**Scope faza 1: contabilitate + gestiune.** Plățile/încasările intră acum,
